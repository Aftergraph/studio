# Security Policy

This repository is a public-facing surface (product, docs, brand, or organization profile).

## Reporting

Do not open public issues for suspected vulnerabilities or credential exposure. Report privately to the maintainer (@JonasAbde) with a minimal reproduction and affected commit.

## Secrets

Never commit credentials, tokens, or signing material. Deployment configuration must reference secrets by name only.

## Supported versions

Only the current `main` branch is maintained.
