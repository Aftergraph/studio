# Motion Specification

Canonical sequence: boundary appears → principal resolves → authority path establishes → execution activates → evidence arrives → verifier evaluates → outcome settles.

| Motion | Duration | Semantic purpose |
|---|---:|---|
| micro | 90–150 ms | focus/hover confirmation |
| state | 160–260 ms | status transition |
| surface | 260–420 ms | spatial continuity |
| evidence arrival | 480–720 ms | receipt linked to source |
| institutional ident | 2 s / 5 s | master sequence without generated logo |

Revocation moves backward across an authority edge and ends with a visible break. Stale state changes to clock geometry and label; it never merely desaturates. Generated cinematic plates may be editorial only. Product UI and evidence are always real captures.

All motion collapses to the final static state under `prefers-reduced-motion: reduce`.
