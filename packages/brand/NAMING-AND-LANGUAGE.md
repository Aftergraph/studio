# Naming and Language Standard

## Canonical master brand

Name: **Aftergraph**  
Descriptor: **Infrastructure and open research for verifiable intelligent systems.**

`ABDE Intelligence`, `AVC`, and `Autonomous Venture Company` are legacy identifiers. They may appear in historical records, migrations, and provenance, but not as a current public parent brand.

## Controlled terms

| Term | Allowed when | Prohibited when |
|---|---|---|
| verified | Named verifier checked named criteria against pinned state | Used as a synonym for “looks correct” |
| production | The referenced deployment is live and its exact revision is recorded | A prototype or local run exists |
| production-ready | Every documented release gate passed for the named scope | Used as general praise |
| conformant | A named conformance suite/version passed | No suite/version is identified |
| certified | An identified authorized certification body issued it | It is merely internally tested |
| secure | A bounded security property and threat model are stated | Used as an absolute claim |
| reproducible | Inputs, environment, procedure, and expected result are available | Only an outcome screenshot exists |
| independent | Executor and evidence producer are organizationally or procedurally independent | The author reran their own test |
| standard | A recognized standards body has published it as such | It is an Aftergraph draft or proposal |
| research draft | Work is public for critique but not an established standard | Never omitted for AIE draft claims |
